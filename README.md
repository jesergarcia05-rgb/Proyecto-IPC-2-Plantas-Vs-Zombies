# Zombis vs. Plantas

Proyecto Java Swing de IPC1, segundo semestre de 2026.

## Ejecutar

Con Java 21 o superior, extrae la carpeta completa y abre **ejecutar.bat** en Windows o ejecuta `sh ejecutar.sh` en Linux/macOS.

- [Instrucciones de compilación y uso](LEEME.md)
- [Manual de usuario PDF](documentacion/Manual_de_usuario.pdf)
- [Manual técnico PDF con UML](documentacion/Manual_tecnico.pdf)
- [Validación y pruebas](VALIDACION.md)

El ejecutable es `dist/ZombisVsPlantas.jar`. Los datos de cada jugador se guardan en `cuentas`; conserva esa carpeta al actualizar de versión.

Incluye imágenes originales, botones compactos, variantes gráficas, 6/5/4 hilos generadores según dificultad, guardado en pausa y estadísticas. Compila con el JDK estándar, sin bibliotecas Java externas.
